# World Development Indicators

This project is a Python workspace for exploring World Development Indicators data.

The current dataset is stored at:

```text
data/raw/P_WDI_40C_5I_25T.xlsx
```

## Setup

Create and activate the virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the core analysis libraries:

```bash
python -m pip install pandas numpy seaborn matplotlib jupyter ipykernel
```

## Start

Open the starter notebook:

```bash
jupyter lab wdi_exploration.ipynb
```
